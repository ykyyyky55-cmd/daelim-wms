코드 규칙

  • 창고 코드 = 거점 이름 + 캠프 번호 + 창고 문자 (예: 본사2A = 본사 거점 · 2번 캠프(방산캠프) · A 창고).
  • WMS 위치는 거점 / 창고코드로 적습니다. 창고를 정하지 않은 재고는 거점 이름만(본사, 김포공장) 적고 '창고 미지정'으로 봅니다.
  • 원료수불부의 지역은 거점 단위 본사 · 김포 두 곳입니다 (방산캠프 → 본사, 김포2공장 → 김포).
  • 구성 창고 13곳은 WMS 환경설정에 기본 등록되어 있으며 지울 수 없습니다. 그 밖의 임시 창고는 환경설정에서 추가합니다.
