대림오일 스마트 WMS 추진 현황 및 사용 안내

전 직원 배포용 — 추진 일정 · 사용 시작 방법 · 거점/창고 코드 · 현장 작업 규칙
대림오일 스마트 WMS는 원부자재·제품의 입출고, 재고, 수불부, 생산 업무를 한곳에서 관리하는 회사 자체 앱입니다. 모든 PC·스마트폰이 같은 데이터를 실시간으로 보며, 10월부터 기본업무에 사용하고 12월 ECOUNT ERP와 연동한 뒤 2027년 1월 전사 활용을 시작합니다.

1. 왜 도입하나요?

재고 정확도입출고를 현장에서 바로 입력(QR 스캔)해 장부와 실물 재고의 차이를 줄입니다.
이중 입력 제거업무일지·수불부·전표를 한 번 입력하면 연결된 장부에 자동 반영되고, 12월부터 ERP로 전송됩니다.
사람 의존 최소화누가 입력해도 같은 양식·같은 규칙으로 기록되고, 모든 작업 이력이 남습니다.
품질·추적원료 LOT → 작업지시서 → 원액 검사 → 포장 LOT → 출하까지 한 흐름으로 추적합니다.

3. 사용 시작하기

  1. 접속: PC·스마트폰 인터넷 창에서 https://ykyyyky55-cmd.github.io/daelim-wms/ (홈 화면의 앱 QR을 찍어도 됩니다)
  2. 가입: [신규 계정 생성]에서 실제 사용하는 이메일로 가입 → 받은 메일의 인증 링크를 누릅니다. (Google 계정 로그인도 가능)
  3. 승인: 관리자가 역할(권한)을 정해 승인하면 사용할 수 있습니다. 승인 전에는 "승인 대기"로 보입니다.
  4. 앱 설치: 머리글의 앱 설치를 누르면 PC·안드로이드는 바로 설치, 아이폰은 공유 → 홈 화면에 추가. 회사에서 받은 설치 파일(윈도우 exe·안드로이드 APK)로도 설치할 수 있습니다.
  5. 현재 작업자: 공용 기기에서는 작업 전에 머리글의 현재 작업자를 본인으로 바꿉니다 (사원증 QR로도 가능).
  6. 사용법: 메뉴 지원 → 매뉴얼에 기능별 단계 설명과 화면이 있습니다.

6. 현장 작업 규칙

  • 입력 기준(정본): 입고·출고·거점 이동은 WMS에 먼저 입력합니다. 12월 ERP 연동 뒤에는 WMS 전표가 ECOUNT로 전송되므로 ECOUNT에 같은 전표를 따로 입력하지 않습니다. 금액·세금계산서는 ECOUNT에서 처리합니다.
  • QR 스캔: 품목·위치 QR 라벨을 스캔해 입력하면 품목코드·위치를 잘못 적는 일이 줄어듭니다. 카메라 권한을 물으면 허용합니다.
  • 인터넷이 안 될 때: 입출고·생산입고·실사·업무일지는 기기에 저장했다가 연결되면 자동 반영됩니다. 머리글의 오프라인 표시로 대기 건수를 확인하세요.
  • 새 버전: 화면 아래 "새 버전이 배포되었습니다"가 뜨면 작성 중인 내용을 저장하고 새로고침합니다.
  • 보안: 배합비·원료 실명·원료코드는 원액 작업지시서(권한자 전용)에서만 다루고, 자료실·채팅에 올리지 않습니다. 계정은 공유하지 않습니다.

7. 앞으로 달라지는 점

  • 12월 ECOUNT ERP 연동: 품목·거래처는 ECOUNT에서 받아오고, WMS의 출고·입고·이동 전표를 ECOUNT로 보냅니다. 연동 전 품목코드·거래처 정리에 협조 부탁드립니다.
  • 제품 추적관리 고도화: 제품 용기·박스에 LOT·제조일·QR을 새겨(레이저 마킹 검토 중) 스캔 한 번으로 원료부터 출하까지 이력을 찾을 수 있게 할 예정입니다.
